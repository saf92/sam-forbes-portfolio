# Personal Maths Website 

Source code for my personal maths website, built using Quarto, and deployed via Netlify.

Assistance from primarily google gemini.

## Tech Stack
- **Quarto:** Document authouring and static site generation (`.qmd`).
- **Observable JS:** Interactive client-side arithmetic practice tools.
- **Netlify:** Automated deployment and hosting.

## Local Development

To run a live-preview server locally while editing content:
```bash
quarto preview
