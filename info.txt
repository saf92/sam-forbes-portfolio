======================================================================
       QUARTO WEBSITE MAINTAINER & REFRESHER CHEAT SHEET
======================================================================

1. STARTING THE ENGINE (TERMINAL)
----------------------------------------------------------------------
Open your terminal in VS Code (Ctrl + ` or Cmd + `) and run:

  cd my_site
  quarto preview

* Note: This opens a browser window. Every time you save a file 
  (Ctrl+S), it will instantly update the site in real time.
* To stop the preview server when finished: Press Ctrl + C

* IF YOU EDIT _quarto.yml OR MOVE/RENAME LARGE FOLDERS:
  You must kill the server (Ctrl + C) and restart it (quarto preview) 
  so it can rebuild the structure properly.


2. EDITING IN VS CODE (HORIZONTAL SCROLL FIX)
----------------------------------------------------------------------
To prevent lines of text from stretching infinitely to the right:
* Press ALT + Z (or Option + Z on Mac) to toggle WORD WRAP.
* This keeps text visible within your window without adding broken breaks.


3. SAFE PARAGRAPH FORMATTING (AVOIDING TYPEWRITER FONT)
----------------------------------------------------------------------
Markdown treats indented text (4+ spaces) or backticks (`) as code, 
turning off text wrapping and forcing a typewriter font. 

To completely immunize your essays from formatting glitches, use 
clean HTML tags directly in your .qmd file:

  <p>This is standard prose. It will automatically wrap perfectly 
  at the edge of any screen. Use <strong>bold</strong> or 
  <em>italics</em> safely here.</p>

  <p>Start a new paragraph by simply opening a new p tag.</p>


4. ADDING A NEW ESSAY FILE
----------------------------------------------------------------------
1. Inside 'my_site/essay_files/', create a new file: 'my_essay.qmd'
2. Put the required header at the absolute top of the file:
   ---
   title: "The Title of Your Piece"
   date: 2026-05-25
   ---
3. Link to it from your index.qmd or essays.qmd page using the path:
   * [Read my piece](essay_files/my_essay.qmd)


5. DEPLOYING LIVE TO NETLIFY
----------------------------------------------------------------------
When everything looks flawless in your local preview, run these 
steps in exact order to push it live:

STEP 1: In your terminal, run the final compile command:
        quarto render

STEP 2: Open your computer's standard file explorer and navigate 
        inside your 'my_site' folder.

STEP 3: Locate the folder named '_site'. This contains the raw, 
        web-ready HTML generated by Quarto.

STEP 4: Log into your Netlify dashboard, open your site project, 
        navigate to the "Deploys" area, and drag and drop ONLY 
        the '_site' folder into the deployment upload box.
